# Noty v1.3.0

本版新增 RtiTek Plane 提醒、工作区主界面和工作流，并修复 tmux 通知跳转。提醒成功打开目标后自动收起，失败时保留。

## 新增功能

- 新建通知时可选择 Tmux AI agent 或 RtiTek Plane 类型。
- Plane 提醒逐条保存在本地，支持打开对应任务、查看历史和恢复提醒。
- Plane 提醒显示任务号和任务名称；评论显示作者、评论时间及前 200 个字符。完整 JSON 默认折叠，可展开查看。
- 工作区主界面可同步 tmux 会话，显示 AI 活动状态，并进入对应终端。
- 新增工作流模板和运行记录，支持按阶段执行手动操作、命令和本地 AI 程序。
- 设置界面支持项目目录过滤、worktree 路径、本地 AI 命令测试和 AI 集成配置。
- 提醒用图标区分项目、Git 分支和 tmux 会话，并显示会话名称。

## 修复

- 点击系统通知会打开 Noty 并定位该条提醒。
- 较大的 Plane JSON 可从 ntfy 附件读取并保存；读取失败后可重试。
- 修复共享 Codex 后台进程继承错误 pane、临时审查目录和后台子进程丢失来源的问题。
- tmux 重启后旧 pane 编号失效或被其他项目复用时，重新查找可确认的来源。
- 原 AI 已退出但唯一匹配的终端仍存在时，仍可跳转。

## 升级说明

- 从 v1.2.x 升级请安装 `Noty-1.3.0-arm64.dmg`。本版更新了应用图标并新增包外 `noty-status` 脚本；应用内更新只替换 `app.asar`，无法交付这些文件。
- Tmux 发送端的来源修复还需要更新通知 hook。发布附件 `ntfy-notify.sh` 对应本版源码，可更新已有的 `~/.claude/hooks/ntfy-notify.sh` 或 `~/.config/noty/ntfy-notify.sh`，并保留现有频道环境配置。
- 安装包适用于 Apple Silicon，采用 ad-hoc 签名，未做 Apple 公证。

## 已知限制

- 多个 AI 会话共用同一 checkout，或历史提醒缺少来源信息时，可能无法唯一定位终端。此时保留提醒并提示失败。
- tmux 重启后，部分历史提醒的会话名称可能仍不准确；点击时会再次校验来源。
- Plane 事件重要性过滤尚未提供，目前保留收到的全部提醒。
