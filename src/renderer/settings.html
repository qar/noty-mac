Claude 通知接入教程
第 0 步：先添加频道
先在上方“添加频道”中填写频道地址（topic 或完整 URL）。下面示例里的变量需要和频道地址一致。
export NTFY_CHANNEL="你的频道地址或 topic"
路径 A（推荐）：Claude Code
在 Claude 任务结束时发送通知。将 NTFY_CHANNEL 设成你的频道地址或 topic。
curl -d "任务完成" https://ntfy.sh/$NTFY_CHANNEL
路径 B（通用）：不使用 Claude Code 也可以
任何终端、脚本、自动化工具都可以发通知，不依赖 Claude Code / tmux / kitty。
curl -H "Title: Noty Test" -H "Tags: white_check_mark" -d "Hello from script" https://ntfy.sh/$NTFY_CHANNEL
tmux/kitty 仅影响“点击通知后跳转终端上下文”的增强能力。即使没有 tmux 或 kitty，你仍然可以正常接收通知。
